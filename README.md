Vice Panels is a fully offline cover art maker that rebuilds your photos as GTA-style multi-panel poster art: drop in 1–4 photos (or start from the bundled samples) and they are clipped into angled, white-keylined panels across four layouts — Poster Five, Trio, Quad and Solo Hero — with every panel individually croppable, zoomable, pannable and swappable. Four one-click colour grades (Leonida Sunset, Neon Nights, Golden Hour, Midnight Noir) wash the whole cover in a Vice City neon-sunset look, layered with hand-drawn vector scenery (palm silhouettes, a skyline, a striped sun, birds), film grain and a vignette, and the genre lettering block — an editable kicker, a big condensed gradient title and an optional roman-numeral badge — is drawn on top. One click exports a share-ready PNG at 1920×1080, 1080×1080, 1080×1350 or 1080×1920, with the composition reflowing to each aspect. No uploads, no network: photos never leave the machine.
## Run it
```sh
node serve.ts
# then open http://localhost:8080
```
